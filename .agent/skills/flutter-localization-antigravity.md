# Flutter Localization in Antigravity

A complete guide for adding multi-language support to a Flutter app using the
`intl` package and the **Flutter Intl** VS Code extension (by Localizely).

---

## Overview of the Stack

| Layer | Tool |
|---|---|
| Translation data | `.arb` files in `lib/l10n/` |
| Code generation | Flutter Intl VS Code extension (uses `intl_utils` under the hood) |
| Runtime library | `intl` + `flutter_localizations` (SDK) |
| Generated output | `lib/generated/l10n.dart` + per-locale `messages_*.dart` files |

---

## Step 1: Add Dependencies to pubspec.yaml

```yaml
dependencies:
  flutter:
    sdk: flutter
  flutter_localizations:
    sdk: flutter
  intl: ^0.20.2          # Match the version pinned by flutter_localizations

flutter_intl:
  enabled: true           # Required — activates the Flutter Intl extension
  class_name: S           # Optional — default is S; change if preferred
  main_locale: en         # Optional — default is en
  arb_dir: lib/l10n       # Optional — where your .arb files live
  output_dir: lib/generated  # Optional — where generated Dart files go
```

Run `flutter pub get` after saving.

---

## Step 2: Initialize the Flutter Intl Extension

Open the VS Code Command Palette (`Cmd+Shift+P` / `Ctrl+Shift+P`) and run:

```
Flutter Intl: Initialize
```

This command:
- Adds `flutter_intl: enabled: true` to `pubspec.yaml` (if not already there)
- Creates `lib/l10n/intl_en.arb` — your main (English) ARB file
- Generates `lib/generated/l10n.dart` and `lib/generated/intl/messages_en.dart`

> **Do not manually edit files in `lib/generated/`** — they are regenerated automatically.
> Do commit them to your repository.

---

## Step 3: Configure MaterialApp

```dart
import 'package:flutter/material.dart';
import 'package:flutter_localizations/flutter_localizations.dart';
import 'generated/l10n.dart'; // auto-generated by Flutter Intl

class MyApp extends StatelessWidget {
  @override
  Widget build(BuildContext context) {
    return MaterialApp(
      localizationsDelegates: [
        S.delegate,
        GlobalMaterialLocalizations.delegate,
        GlobalWidgetsLocalizations.delegate,
        GlobalCupertinoLocalizations.delegate,
      ],
      supportedLocales: S.delegate.supportedLocales,
      home: MyHomePage(),
    );
  }
}
```

## Step 4: Add Translation Keys in the Main ARB File

Edit `lib/l10n/intl_en.arb`. Save the file and the extension regenerates the Dart code automatically.

### Simple string

```json
{
  "appTitle": "My App",
  "welcomeMessage": "Welcome to My App!"
}
```

### String with a placeholder

```json
{
  "greetUser": "Hello, {name}!",
  "@greetUser": {
    "placeholders": {
      "name": { "type": "String" }
    }
  }
}
```

### Plural

```json
{
  "itemCount": "{count, plural, zero{No items} one{1 item} other{{count} items}}",
  "@itemCount": {
    "placeholders": {
      "count": { "type": "int" }
    }
  }
}
```

### Gender / Select

```json
{
  "userStatus": "{gender, select, male{He is online} female{She is online} other{They are online}}",
  "@userStatus": {
    "placeholders": {
      "gender": { "type": "String" }
    }
  }
}
```

### Formatted number

```json
{
  "totalAmount": "Total: {amount}",
  "@totalAmount": {
    "placeholders": {
      "amount": {
        "type": "double",
        "format": "currency",
        "optionalParameters": {
          "symbol": "$",
          "decimalDigits": 2
        }
      }
    }
  }
}
```

### Formatted date

```json
{
  "todayDate": "Today is {date}",
  "@todayDate": {
    "placeholders": {
      "date": {
        "type": "DateTime",
        "format": "yMMMd"
      }
    }
  }
}
```

## Step 5: Reference Keys in Dart Code

```dart
// Simple string
Text(S.of(context).appTitle)

// Without context (e.g., in a ViewModel or outside widget tree)
Text(S.current.appTitle)

// With placeholder
Text(S.of(context).greetUser("Sarah"))

// Plural
Text(S.of(context).itemCount(3))

// Gender
Text(S.of(context).userStatus("female"))

// Formatted number or date — pass the raw value, the ARB format handles formatting
Text(S.of(context).totalAmount(9999.99))
Text(S.of(context).todayDate(DateTime.now()))
```

## Step 6: Add More Locales

Open the Command Palette and run:

```
Flutter Intl: Add locale
```

Type the locale code when prompted (e.g., `ar`, `fr`, `es`, `de`, `zh`).

This creates `lib/l10n/intl_ar.arb` (empty keys matching the main ARB). Fill in the translated values:

```json
{
  "appTitle": "تطبيقي",
  "welcomeMessage": "مرحباً بك في تطبيقي!"
}
```

Save the file — the extension regenerates `lib/generated/` automatically.

---

## Step 7: iOS Platform Configuration

For iOS to pick up the new locales, add them to `ios/Runner/Info.plist`:

```xml
<key>CFBundleLocalizations</key>
<array>
    <string>en</string>
    <string>ar</string>
    <string>fr</string>
</array>
```

> Keep this list in sync with the locale codes in `lib/l10n/`.

---

## Step 8: Change Locale Programmatically (Optional)

```dart
// Force a specific locale at runtime
await S.load(Locale('ar'));

// Read the current locale
String current = Intl.getCurrentLocale(); // e.g. "ar"
```

To rebuild the UI when locale changes, wrap your `MaterialApp` in a
`StatefulWidget` and use `setState` after calling `S.load`.

## Extract Strings with Code Actions (Shortcut Workflow)

Instead of editing ARB files directly, you can write the string in Dart first:

1. Type a hardcoded string in your Dart file, e.g. `"Submit"`.
2. Hover over it — a lightbulb (💡) appears.
3. Click **Extract to ARB files**.
4. Enter a key name (e.g., `buttonSubmit`).
5. The string is removed from Dart and replaced with `S.of(context).buttonSubmit`,
   and the key is added to all ARB files automatically.

## Generated File Structure

```
lib/
├── l10n/
│   ├── intl_en.arb         ← you edit this
│   ├── intl_ar.arb         ← you edit this
│   └── intl_fr.arb         ← you edit this
└── generated/              ← DO NOT EDIT (auto-generated)
    ├── l10n.dart           ← defines S class and S.delegate
    └── intl/
        ├── messages_all.dart
        ├── messages_en.dart
        ├── messages_ar.dart
        └── messages_fr.dart
```

## Using Antigravity for This Task

When working in Antigravity (Google's agentic coding IDE):

1. Open the **Agent** panel (`Cmd/Ctrl + L`).
2. Describe what you need — for example:
   - *"Add Arabic and French localization to my Flutter app"*
   - *"Extract all hardcoded strings to ARB files and replace with S.of(context) calls"*
   - *"Add a plural key for item count in my ARB file"*
3. Antigravity will edit `pubspec.yaml`, create/update ARB files, and update your Dart code.
4. After Antigravity makes the changes, run the `Flutter Intl: Initialize` (first time)
   or just save the ARB file to trigger regeneration.
5. Run `flutter run` to verify the translations appear correctly.

## Common Pitfalls

- **`lib/generated/` not found**: Run `Flutter Intl: Initialize` from the Command Palette.
  Also check that `flutter_intl: enabled: true` is in `pubspec.yaml`.
- **Keys not updating**: Save the `.arb` file — the extension only triggers on save.
- **`S.of(context)` returns null / crashes**: Make sure `S.delegate` is in
  `localizationsDelegates` and `S.delegate.supportedLocales` is in `supportedLocales`.
- **Missing translations on iOS**: The locale must be listed in `ios/Runner/Info.plist`
  under `CFBundleLocalizations`.
- **Placeholder type mismatch**: ARB placeholder `type` must match the Dart argument type
  (e.g., `"type": "int"` expects an `int`, not a `String`).
- **Generated code conflicts with intl version**: If you see version mismatch errors,
  pin the `intl` version in `pubspec.yaml` to match `flutter_localizations`'s constraint
  (`flutter pub deps | grep intl` to find the pinned version).

## Quick Reference: ARB Key Formats

| Pattern | ARB format |
|---|---|
| Simple string | `"key": "value"` |
| Placeholder | `{name}` inside value + `@key` metadata |
| Plural | `{count, plural, zero{} one{} other{}}` |
| Select / Gender | `{gender, select, male{} female{} other{}}` |
| Number format | `@key` → `placeholders` → `type: double` + `format: currency` |
| Date format | `@key` → `placeholders` → `type: DateTime` + `format: yMMMd` |
